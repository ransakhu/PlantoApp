 🌱 Plant Reminder App

An iOS app built with SwiftUI that reminds users to water their plants and track their progress.



💡 Overview
The app allows users to:
- Add and manage plant reminders  
- Receive daily watering notifications  
- Track how many plants were watered today  


 🛠️ Technologies Used
- Swift  
- SwiftUI  
- MVVM architecture  
- UserNotifications framework
